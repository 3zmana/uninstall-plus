# Changelog

## 1.0.1 — 2026-10-21

First public release.

- Preferences dialog in the main menu (Ctrl+,)
- Interface language: System (default), English or French
- Theme: System (default), Light or Dark
- Full French translation
- Search bar and filters aligned with the list in a centered column
- Application ID is `io.github._3zmana.UninstallPlus`
- License: MIT

## 1.0.0

- RPM Packages tab: list, search, filter by repository, "Installed by me only",
  details, uninstall with a preview of the DNF transaction
- Flatpak tab: list and uninstall applications, with automatic cleanup of unused runtimes
- Repositories tab: DNF repositories (URL, COPR, manual entry) and Flatpak remotes
